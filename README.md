# 星夜塔罗

一个可直接在浏览器运行的中文塔罗牌占卜单页应用。项目模拟提问、选择牌阵、洗牌、切牌、抽牌、逐张翻牌和综合解读的完整流程，适合用作学习、娱乐与自我反思。

> 塔罗仅供娱乐与自我反思，不构成医疗、法律、投资等专业建议。重要决定请结合真实信息并咨询相应专业人士。

## 项目特点

- 内置完整 78 张塔罗牌，包括 22 张大阿卡纳和 56 张小阿卡纳
- 权杖、圣杯、宝剑、星币四组花色，每组包含 Ace 至 10 与四张宫廷牌
- 单张牌、时间流三张牌、行动三张牌、五张牌和简化凯尔特十字
- 完整的洗牌、切牌、抽牌与逐张翻牌动画
- 正位与逆位随机生成，抽牌不会重复
- 结合问题类型、牌阵位置、正逆位和关键词生成中文综合解读
- 使用浏览器 `localStorage` 保存最近 10 次占卜记录
- 支持记录查看、删除和清空，刷新页面后仍然保留
- 纯前端实现，无后端、无第三方库、无外部图片依赖
- 适配桌面端与移动端，支持键盘操作
- 支持系统 `prefers-reduced-motion` 减少动态效果设置

## 占卜流程

1. 输入想探索的问题，并选择感情、事业、学业、财运、人际或综合类型。
2. 选择适合当前问题的牌阵。
3. 完成洗牌与切牌。
4. 根据牌阵要求逐张抽取塔罗牌。
5. 逐张翻开牌面，查看牌位、正逆位和关键词。
6. 阅读综合解读，也可以将本次结果保存到本机历史记录。

## 本地运行

直接双击 `index.html`，即可在浏览器中使用完整功能。

也可以在项目目录启动一个简单的本地静态服务器：

```powershell
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

## 部署到 GitHub Pages

1. 把项目文件推送到 GitHub 仓库的 `main` 分支。
2. 进入仓库的 `Settings`。
3. 打开左侧的 `Pages`。
4. 在 `Build and deployment` 中把 `Source` 设置为 `Deploy from a branch`。
5. 选择 `main` 分支和 `/ (root)` 文件夹。
6. 点击 `Save`。

部署完成后，页面地址通常为：

```text
https://你的用户名.github.io/你的仓库名/
```

## 数据与隐私

本项目不向服务器发送问题或占卜结果。历史记录只保存在当前浏览器的 `localStorage` 中，清除浏览器数据或更换设备后不会自动同步。

由于本地文件和 GitHub Pages 属于不同的浏览器来源，两个版本的历史记录不会互通。

## 浏览器支持

建议使用最新版 Chrome、Edge、Firefox 或 Safari。页面本身不需要联网，但 GitHub Pages 地址需要网络访问。
