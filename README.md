# 星夜三占

一个可直接在浏览器运行的中文三合一占卜单页应用，包含塔罗牌、小六壬和六爻三个独立模块。项目模拟提问、起课或摇卦、结果解读和本地历史保存的完整流程，适合用作传统文化体验、学习、娱乐与自我反思。

> 本工具仅供传统文化体验、娱乐与自我反思，不构成医疗、法律、投资、婚恋等专业建议；请理性看待。

## 项目特点

- 塔罗牌：内置完整 78 张牌，包括 22 张大阿卡纳和 56 张小阿卡纳
- 塔罗牌：支持单张牌、时间流三张牌、行动三张牌、五张牌和简化凯尔特十字
- 塔罗牌：支持洗牌、切牌、去重抽牌、正逆位和逐张翻牌
- 塔罗牌：洗牌增加牌堆厚度与交错搓牌动画，切牌分为三叠后再合成
- 塔罗牌：抽牌改为 78 张牌背扇形展开，凭直觉点选后飞入牌位槽
- 塔罗牌：翻牌带短暂停顿和金色闪光，并支持跳过动画
- 小六壬：内置大安、留连、速喜、赤口、小吉、空亡六宫完整数据
- 小六壬：按提问、起课方式、落宫计算、结果解读逐步进行
- 六爻：内置八卦、完整六十四卦、卦序、上下卦、卦象符号和五行域别简读
- 六爻：固定三背为老阳、三字为老阴、两背一字为少阳、两字一背为少阴
- 六爻：支持初爻至上爻逐爻摇卦、自动摇完六爻、动爻翻转、本卦和变卦
- 六爻：新增六亲、六神与世应装卦层，按京房八宫卦序定卦宫与世爻，按日干起六神
- 六爻：可选择起卦日期，页面自动换算当日干支
- 三个模块统一使用深色神秘风和响应式布局
- 使用 WebAudio 实时合成塔罗、小六壬和六爻的仪式音效，无外部音频文件
- 使用浏览器 `localStorage` 保存最近 50 次占卜记录
- 历史记录带 `type` 字段，旧塔罗记录会自动视为塔罗类型
- 支持记录类型筛选、查看、删除单条和清空
- 结果页支持重新占卜、重新起课、保存记录和复制解读文本
- 纯前端实现，无后端、无第三方库、无外部图片依赖
- 适配桌面端与移动端，支持键盘操作
- 支持系统 `prefers-reduced-motion` 减少动态效果设置

## 模块流程

### 塔罗牌

1. 输入问题并选择感情、事业、学业、财运、人际或综合类型。
2. 选择牌阵并完成洗牌、切牌。
3. 根据牌阵要求逐张抽牌和逐张翻牌。
4. 阅读牌位、正逆位、关键词和综合解读。

### 小六壬

1. 输入问题并选择占问类型。
2. 选择时间起课或报数起课。
3. 时间起课支持手动确认农历月、农历日与时辰；使用当前时间时会明确提示农历日期属于简化换算。
4. 报数起课输入三个正整数：第一数从大安起顺数，第二数从第一宫继续顺数，第三数从第二宫继续顺数。
5. 查看每一步计算公式、三宫路径、起因/过程/结果定位和综合解课。
6. 保存记录或复制解读文本。

小六壬为传统民俗简化方法，仅供文化体验与自我反思。

### 六爻

1. 输入问题、选择占问类型，并确认起卦日期（默认今天，用于起六神）。
2. 由下至上完成六次摇卦，也可以自动摇完六爻；未满六次不会开放结果。
3. 查看每次三枚铜钱的正反结果、对应爻象和“已摇 x/6 爻”进度。
4. 查看本卦、动爻位置、动爻翻转后的变卦，以及静卦提示。
5. 查看六亲六神装卦表：爻位、六神、六亲、纳甲地支、爻象与世应标记。
6. 阅读现状、变化趋势、建议和事业、感情、财运、学业、人际简读。
7. 保存记录或复制解读文本。

六爻排盘为简化版：已包含八宫卦序、纳甲、六亲、六神与世应，未实现月建日辰旺衰、用神取用、伏神与神煞体系；仅供娱乐与自我反思。

## 六亲六神规则说明

- **卦宫与世应**：采用京房八宫卦序（乾坎艮震巽离坤兑），由程序按本宫卦逐爻变出八卦，并给出世爻位置；应爻与世爻相隔三位。
- **纳甲**：乾纳甲、坎纳戊、艮纳丙、震纳庚顺行，巽纳辛、离纳己、坤纳乙、兑纳丁逆行，得到每爻地支。
- **六亲**：以世爻五行为「我」，生我者为父母、同我者为兄弟、我生者为子孙、我克者为妻财、克我者为官鬼。
- **六神**：以起卦日干起，青龙、朱雀、勾陈、螣蛇、白虎、玄武，阳日顺行、阴日逆行。
- **干支换算**：由公历日期经儒略日换算日干支，用于六神起卦。

## 本地运行

直接双击 `index.html`，即可在浏览器中使用完整功能。

也可以在项目目录启动一个简单的本地静态服务器：

```powershell
node tools\serve.js 3000
```

然后访问：

```text
http://localhost:3000/
```

## 开发辅助脚本

`tools/` 目录中的脚本只用于开发期校验，页面运行不依赖它们：

```powershell
node tools\chart-test.js    # 校验八宫卦序、纳甲、六亲、六神与干支换算
node tools\browser-test.js  # 用无头 Chrome 跑通三个模块的完整流程
node tools\screenshot.js liuyao   # 截取六爻结果页，输出到 tools/screenshots
```

`browser-test.js` 会驱动真实 Chrome 依次完成塔罗洗牌抽牌、小六壬报数起课、六爻摇卦与解卦，
并校验历史记录写入与筛选行为。


## 数据与隐私

本项目不向服务器发送问题或占卜结果。三个模块共用一套本地历史记录，数据只保存在当前浏览器的 `localStorage` 中，清除浏览器数据或更换设备后不会自动同步。旧版本保存的塔罗记录没有 `type` 字段时，会自动按塔罗记录处理；旧版本保存的小六壬与六爻记录也会以兼容视图正常显示。

由于本地文件和 GitHub Pages 属于不同的浏览器来源，两个版本的历史记录不会互通。

## 浏览器支持

建议使用最新版 Chrome、Edge、Firefox 或 Safari。页面本身不需要联网，但 GitHub Pages 地址需要网络访问。
